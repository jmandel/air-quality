PROBLEM:
--------
Multiple browser tabs streaming the same sensor data resulted in redundant 
database entries (same reading stored 2-3x per tab).

SOLUTION:
---------
Implemented server-side deduplication with 10-second time window.
Readings with identical (sensorId, value, state) within 10 seconds are 
silently dropped.

---------------
1. index.ts              - Added deduplication logic (isDuplicate function)

KEY FEATURES:
-------------
✓ Two-tier system: In-memory cache + database fallback
✓ 10-second deduplication window (configurable)
✓ Automatic cache cleanup every 30 seconds
✓ API returns inserted/duplicates counts
✓ Zero user-visible changes
✓ Minimal performance overhead (<1ms typical)
