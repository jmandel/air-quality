KEY CLARIFICATIONS
------------------
✅ Units Storage:
   - Human-readable TEXT in sensors.unit column
   - Examples: "ppm", "°C", "µg/m³"
   - NOT a separate unit_id or units table
   - Stored ONCE per sensor (canonical form)
   - Not extracted from state field

✅ Aggregation Strategy:
   - Aggregate ALL data from day 1 (not just >7 days old)
   - Real-time: flush completed minutes every 60 seconds
   - Minutely summaries stored forever
   - Raw data deleted after 7 days

✅ Schema Design:
   sensors table:
     - id: INTEGER PRIMARY KEY (1-byte reference)
     - name: TEXT (SSE 'id' field, e.g., "sensor-co2")
     - display_name: TEXT (SSE 'name' field, e.g., "CO₂")
     - unit: TEXT (human-readable, e.g., "ppm")
   
   readings table (raw, 7-day retention):
     - ts: INTEGER (timestamp ms)
     - sensor_id: INTEGER (foreign key)
     - value: REAL
   
   readings_aggregated table (forever):
     - minute_ts: INTEGER (rounded to minute)
     - sensor_id: INTEGER (foreign key)
     - avg_value, min_value, max_value: REAL
     - sample_count: INTEGER
