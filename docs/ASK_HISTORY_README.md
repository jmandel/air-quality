# Ask History Feature

## Overview

The ask history feature automatically saves all questions, generated scripts, and dashboard responses. Users can star their favorite queries to create quick-access pills and browse/replay their entire query history.

## Features

### 1. Automatic History Tracking
Every query submitted to `/api/ask` is automatically saved with:
- Question text
- Generated analysis script (`analyze.ts`)
- Dashboard response (complete with data and visualizations)
- Timestamp
- Unique ID based on timestamp + slugified question

### 2. Starred Queries
- **Star any query** to promote it to the "Starred Queries" section
- Top 5 starred queries shown as **pills** at the top of the ask page
- Starred pills have a ⭐ prefix and special styling
- Click any starred pill to instantly re-run that query

### 3. Query History Catalog
- Browse last 1000 queries in chronological order (newest first)
- Each entry shows:
  - Question text
  - Relative time ("just now", "5m ago", "2h ago", "3d ago")
  - Star button (☆/⭐)
  - Trash button (🗑️)
- Click any question to re-run it
- Starred items show filled star (⭐)

### 4. Trash Management
- Trashing moves items to `asked/trashed/` directory
- Trashed items are hidden from history list
- Items can be untrashed via API

## Directory Structure

```
~/app/asked/
├── 2025-11-16T03-15-22-421Z_what-is-the-current-co-level.json
├── 2025-11-16T03-15-22-421Z_what-is-the-current-co-level.ts
├── starred/
│   └── 2025-11-16T03-15-22-421Z_what-is-the-current-co-level.json → (symlink)
└── trashed/
    └── (trashed items moved here)
```

### File Format

**Metadata JSON** (`{id}.json`):
```json
{
  "id": "2025-11-16T03-15-22-421Z_what-is-the-current-co-level",
  "timestamp": "2025-11-16T03:15:22.421Z",
  "question": "What is the current CO₂ level?",
  "answer": {
    "summary": "Current CO₂ is 984 ppm",
    "blocks": [...]
  },
  "conversationId": "cli-1763262922421"
}
```

**Script** (`{id}.ts`):
The complete TypeScript script generated by Shelley for this query.

## API Endpoints

### GET /api/ask/history
Get all history items with optional filters.

**Query params:**
- `limit` - Max items to return (default: 1000)
- `starred` - Filter by starred status (true/false)
- `trashed` - Include trashed items (true/false)

**Response:**
```json
{
  "items": [
    {
      "id": "2025-11-16T03-15-22-421Z_what-is-the-current-co-level",
      "timestamp": "2025-11-16T03:15:22.421Z",
      "question": "What is the current CO₂ level?",
      "starred": true,
      "trashed": false,
      "scriptPath": "/home/exedev/app/asked/...",
      "metadataPath": "/home/exedev/app/asked/..."
    }
  ]
}
```

### GET /api/ask/starred
Get top 5 starred items.

**Response:** Same format as `/api/ask/history`

### POST /api/ask/star/:id
Star an item.

**Response:**
```json
{ "success": true }
```

### DELETE /api/ask/star/:id
Unstar an item.

### POST /api/ask/trash/:id
Move item to trash.

### DELETE /api/ask/trash/:id
Restore item from trash (untrash).

## Implementation Details

### Modules

**`ask-history.ts`**
- Core history management functions
- File I/O operations
- Starring/unstarring (via symlinks)
- Trashing/untrashing (via file moves)
- History retrieval with filters

**`ask-api-routes.ts`**
- HTTP route handlers for all history endpoints
- Called from `index.ts` via custom fetch handler

**`ask-helper.ts`**
- Modified to call `saveToHistory()` after successful analysis
- Saves question, answer, and script content

**`index.ts`**
- Custom `fetch()` handler routes dynamic paths (`:id` patterns)
- Falls through to default Bun routing if not an ask API route

**`ask.html`**
- Added "STARRED QUERIES" section
- Added "📚 Query History" catalog
- Styled starred pills with ⭐ prefix
- Action buttons for star/trash operations

**`ask.ts`**
- `loadStarredQueries()` - Fetch and render starred pills
- `loadHistory()` - Fetch and render full history catalog
- `toggleStar()` - Star/unstar items
- `trashHistoryItem()` - Move items to trash
- `formatTimestamp()` - Pretty relative time formatting

## Usage Examples

### Starring a Query via API
```bash
curl -X POST http://localhost:3000/api/ask/star/2025-11-16T03-15-22-421Z_what-is-the-current-co-level
```

### Listing Starred Queries
```bash
curl http://localhost:3000/api/ask/starred | jq '.items[].question'
```

### Trashing a Query
```bash
curl -X POST http://localhost:3000/api/ask/trash/2025-11-16T03-15-22-421Z_test
```

### Getting All History
```bash
curl http://localhost:3000/api/ask/history?limit=50 | jq '.items | length'
```

## Benefits

1. **Query Reusability**: Quickly re-run common queries via starred pills
2. **Audit Trail**: Complete history of all questions asked
3. **Script Library**: Every generated analysis script is preserved
4. **Reproducibility**: Re-run any historical query with a single click
5. **Learning**: Review successful queries and their scripts
6. **Debugging**: Compare multiple runs of the same question over time
